# 划词翻译采用用户授权的网站访问权限

划词翻译默认关闭，因为扩展若要在用户选中网页文本后立即显示入口，就必须持续运行于相应网页，而现有 `activeTab` 权限不足以提供这种体验。用户全局开启功能时申请全部普通 HTTP/HTTPS 网站权限，也可以通过网站覆盖设置仅为当前网站开启并只申请该网站权限；网站设置优先于全局设置，因此全局开启后仍可在敏感网站停止监听，但 Chrome 无法从已授予的通配权限中单独扣除该网站。扩展在用户仅形成选区时不把文本发送到后台或写入存储，只有点击翻译入口才启动翻译任务，成功结果才按现有规则进入本地缓存。这保留了默认最小权限和明确触发发送的产品边界，代价是首次使用前需要额外设置和授权。
