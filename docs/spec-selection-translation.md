# 划词翻译规格

## 目标

用户在普通网页中选中一段非编辑内容后，可以在选区附近点击插件图标，并在原地查看译文，不必翻译整页或打开右键菜单。现有右键菜单继续作为独立备用入口，并使用相同结果浮层。

## 权限与偏好

- 划词翻译默认关闭。设置页可为全部 HTTP/HTTPS 网站开启；扩展弹窗不再提供网站级开关。
- 已保存的网站覆盖设置继续优先于全局设置并保持原有行为，但本次界面收敛不提供新增或修改网站覆盖的入口。
- 全局开启会申请全部普通网站权限；关闭全局设置会撤销相应授权。
- 仅形成选区时，文本只保留在页面内存；只有点击翻译入口后才发送到扩展后台和用户配置的 LLM。

## 选区与入口

- 鼠标拖选和键盘选区均受支持；选区稳定约 100ms 后显示入口，拖选过程中不显示。
- 鼠标选区不抢焦点。键盘选区形成后入口获得焦点，支持 Enter、空格触发和 Escape 关闭。
- 入口使用现有插件图标，尺寸 28×28px，优先位于选区最后一行末端外侧，并在视口边缘自动避让，不遮挡选中文字。
- 有效选区至少包含一个非空白字符，最多 5,000 字符。超限时点击入口只显示原地说明，不发送请求。
- 输入框、编辑器、密码字段、代码块、命令行、日志、明确标记为不翻译的内容及普通 iframe 均排除。
- 正式支持普通文档和开放 Shadow Root，包括动态添加的开放 Shadow Root；封闭 Shadow Root 仅尽力兼容。

## 翻译浮层

- 页面同时只保留一个当前划词翻译。新选区立即淘汰旧入口或浮层；旧请求尽量取消，无法取消时忽略迟到结果。
- 入口在原锚点展开为浮层。浮层展示原文、加载状态、译文、复制译文、失败重试、打开设置和关闭。
- 当选区是一个自然语言单词时，浮层在原词下方展示音标和朗读图标；点击图标使用浏览器语音合成朗读原词。单词可包含词内撇号或连字符，包含空格的短语和句子不进入该模式。
- 浮层宽度约 360px，最大高度为视口 60%；长原文默认显示三行并可展开，译文完整展示，内容区域可滚动。
- 新选区、点击外部、Escape、页面导航或选区离开视口时关闭。滚动和窗口缩放时重新定位；复制和重试不关闭；结果不定时消失。
- 未配置 LLM 时仍显示入口，点击后显示“请先配置 LLM”和“打开设置”。
- 网络、超时、限流和响应格式错误提供重试；配置、认证和 CORS 错误同时提供打开设置。错误不会触发无限自动重试。

## 翻译行为

- 只发送用户选中的文本，不自动附带周边段落。
- 单词划词翻译在同一次 LLM 请求中通过独立的 `sourcePhonetic` 字段要求返回原词的 IPA 音标；普通短语和句子继续只要求译文。提示词明确禁止返回译文读音、拼音或罗马字；响应边界会校验 IPA 斜杠格式、目标文字脚本及中文目标语言的拼音声调写法。校验失败时保留译文并省略音标。校验后的音标状态随译文进入本地翻译缓存，朗读不调用外部语音服务。
- 复用现有目标语言、网站提示词、术语表和本地翻译缓存。
- 划词翻译优先于尚未发出的整页翻译批次，但不取消已经发出的请求。
- 图标和浮层位于开放 Shadow Root 内，以隔离网页样式并保持可测试、可诊断和可访问。

## 验收

浏览器端到端测试覆盖鼠标与键盘主路径、全局和单站权限、即时开关、排除内容、长度上限、点击后才发送、加载和错误恢复、单实例防串位、任务优先级、缓存与网站偏好复用、单词音标与朗读、右键菜单兼容、视口定位及开放 Shadow Root。位置计算、单词识别和交互状态转换仅在确有必要时补充纯函数测试。
